# Experiment Studies

The combined report for the Predictive Coding experiments developed on the
`haoran-experiments` branch is
[`haoran-experiments-report.md`](haoran-experiments-report.md).

The integration status, evidence audit, and reproduction gate are recorded in
[`integration-verification.md`](integration-verification.md).

Study-level records:

- [`pc-relaxation-plasticity/`](pc-relaxation-plasticity/) — relaxation-step
  ablation across static MNIST, SplitMNIST, and Permuted MNIST.
- [`pc-network-scale/`](pc-network-scale/) — width/depth architecture ablation
  with a recorded invalid-run correction and full v2 rerun.

Each study contains its immutable protocol, run ledger, raw-artifact pointers,
deterministic summaries, evaluation, synthesis, and research graph.
