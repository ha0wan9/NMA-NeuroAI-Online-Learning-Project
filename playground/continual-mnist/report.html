🧠 Continual Learning with Predictive Coding + CLASSP

Experiment Report — July 21, 2026 · NVIDIA RTX 4090 · Permuted MNIST

1. Context

Neural networks trained with backpropagation suffer from catastrophic forgetting: when learning a new task, previously acquired knowledge is overwritten. This is a fundamental limitation for any system that must learn continuously from a stream of experience — including both artificial agents and biological brains.

Two complementary research directions address this:

  • Predictive Coding (PC) — a biologically-motivated learning rule where neural activity settles into an energy-minimizing configuration before weights are updated. This "prospective configuration" (Song et al., Nature Neuroscience 2024) should produce smaller, better-targeted weight changes that disturb previous knowledge less.
  • CLASSP (Ludwig 2024, arXiv:2405.09637) — a drop-in optimizer that generalizes AdaGrad. It maintains a per-weight scaling factor based on historical gradient magnitudes (decay) and only updates weights above a gradient threshold (sparsity). This naturally protects weights that were important for prior tasks.

This experiment systematically tests whether PC + CLASSP together outperform either alone — on the classic Permuted MNIST continual learning benchmark.

Core hypothesis: PC's intrinsic stability (weight updates are informed by settled latent states) + CLASSP's adaptive per-weight protection (weights important to past tasks receive smaller updates) should be synergistic — producing both higher final accuracy and lower forgetting than either mechanism alone.

2. Protocol

🔬 Benchmark

Permuted MNIST — each task applies a fixed random pixel permutation to MNIST digits.

  • 20 tasks (full sweep) + 50 tasks (scaling test)
  • 1 epoch per task, single pass, no replay
  • Task ID unavailable to model
  • MLP: 784 → 256 → 256 → 10, ReLU

⚙️ Configurations

  • BP: Adam or SGD, CrossEntropyLoss
  • PC: PCTrainer T=20, SGD x-opt (lr=0.01), Adam/CLASSP p-opt
  • iPC: update_p_at='all' (intermediate weight updates)
  • CLASSP: p ∈ {1,2,3}, threshold ∈ {0, 1e-6, 1e-5}
  • Batch size 500, seeds 42

4. Findings & Interpretation

Finding 1: PC alone ≈ BP — but CLASSP changes everything

With Adam, PC (53.8%) and BP (54.0%) are statistically indistinguishable on 20 tasks. Neither has an inherent advantage in this regime. But CLASSP is a force multiplier for PC: +16pp accuracy on PC vs only +6pp on BP. Why? PC's weight updates are already more targeted (informed by converged latent states), so CLASSP's per-weight importance tracking has a cleaner signal to work with. BP's noisier gradients dilute CLASSP's effectiveness.

Finding 2: The threshold matters critically

CLASSP's gradient threshold creates a sharp cliff: th=1e-5 is optimal (69.9%), th=1e-6 destroys PC (20.1%). This suggests PC gradients have a specific dynamic range where the threshold must be tuned — too aggressive and learning collapses, too conservative (th=0) and forgetting is suboptimal.

Finding 3: p=3 emerges as optimal for PC

While BP benefits most from p=1 (the AdaGrad regime — L1 accumulation), PC benefits from p=3. Higher p means the decay is softer (closer to uniform scaling), suggesting PC's weight updates are more uniformly distributed across parameters. BP concentrates updates in fewer weights (so L1 decay protects them better), while PC spreads learning more evenly.

Finding 4: iPC fails on small architectures

Salvatori et al. (2022) showed iPC outperforms standard PC on CNNs and AlexNet, but our results confirm it fails on small MLPs (15.6% accuracy). Intermediate weight updates (update_p_at='all') disrupt the inference dynamics and produce unstable gradients at this scale.

Finding 5: PC+CLASSP scales better

The PC+CLASSP advantage is maintained and slightly grows from 20→50 tasks. This is the pattern you'd expect from a mechanism that genuinely reduces interference rather than just delaying it — the benefit compounds, making PC+CLASSP the clear winner for longer task sequences.

5. Perspective

What this means for NeuroAI: Predictive coding has long been promoted as a biologically plausible alternative to backpropagation, but its continual learning advantage has been inconsistent in the literature. These results suggest PC's advantage is latent — it requires the right optimizer to unlock. CLASSP provides that key. This is philosophically satisfying: biological synapses don't use Adam, but they do exhibit history-dependent plasticity (metaplasticity). CLASSP's per-weight decay is a reasonable abstraction of synaptic metaplasticity, and PC's inference-then-update cycle mirrors cortical processing. The combination feels less like an engineering hack and more like two biologically-motivated mechanisms that genuinely complement each other.

Three open questions from this work:

  1. Does this scale to deeper architectures? Our MLP is shallow (2 hidden layers). The PC library warns that more PC layers need more inference iterations. Does the PC+CLASSP advantage hold for 4+ layers?
  2. Can HLOP improve these results further? We built the HLOP module (Oja's rule orthogonal projection) but didn't run it yet. HLOP operates on a different principle — projecting weight updates orthogonal to previously learned subspaces — so it could be combined with CLASSP.
  3. What about single-pass online learning? The Dohare et al. (2023) protocol uses online SGD (no epochs, single pass). Our 1-epoch setting is close but still revisits each sample once. True online single-pass is the acid test.

cd playground/continual-mnist
